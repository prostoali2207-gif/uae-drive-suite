# FleetDesk UX Reference Library

This library stores reusable UX judgment for FleetDesk. It is not a gallery of attractive screens.

## Structure

- `patterns/` — approved reusable FleetDesk interaction patterns.
- `reviews/` — task-specific benchmark comparisons.
- `screenshots/` — optional screenshots supplied by Ali or captured from publicly accessible references. Do not commit private customer data.
- `REVIEW_TEMPLATE.md` — required format for new benchmark reviews.

## Rule

A reference is useful only when it explains:

- the manager job;
- why the interaction works;
- what FleetDesk should reuse;
- what FleetDesk should not copy;
- which risks still require testing.
